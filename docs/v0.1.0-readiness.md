The Rust quality gate also runs `side_stream_delivery`: paused writers
cannot advance a sync token, limited to-device batches retain omitted
messages, and failed writers cannot stall the watermark. A drained-mailbox
restart test checks that future events remain above issued tokens after
queue rows disappear. Call-churn
measurements count unique senders and await background tasks.

## Boundaries to disclose

The retired slot-wise merge is not equivalent to Matrix state resolution.
Counterexamples are permanent tests; forks with different states use the room
version's resolver. A release must not resurrect the retired merge or claim
its disproved theorem. ADR 0005 and the source tests explain that decision.

The workload for first-sight keys regressed at 50,000 slots after the key
intern change. [benchmarks.md](benchmarks.md) publishes the raw baseline/candidate
measurements from alternate rounds and their controls. Extensions to the
federated comparison remain in [#647](https://github.com/tuna-os/spindle/issues/647).
The completed #42 client workload is the maturity gate's comparison, not universal parity.

Account-driven storage growth has no general per-account quota. Run closed
registration, a bounded ingress, process memory limits and a monitored storage
quota. Do not describe an unrestricted open-registration deployment as covered
by this release's operator readiness.

Spindle admin console

Baked-in operator console. Every action below calls the admin API with your access token; nothing here bypasses it.

  • Onboarding
  • Voice & video (SFU)

Onboarding

  1. Create your account on this server, then make it an admin with spindle promote-admin <config> <localpart>.
  2. Sign in with any Matrix client and copy the access token.
  3. Paste the token below. It stays in this tab's session storage and is sent as a Bearer token on every admin API call.

Voice & video (SFU)

Reads and flips the runtime switch at GET / PUT /_spindle/admin/v1/rtc/sfu with body {"enabled": true|false}. Turning the switch off stops the supervised sidecar and silences every minter path; turning it on starts it again on the next tick.

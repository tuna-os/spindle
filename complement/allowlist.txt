# Complement tests Spindle must pass — the conformance ratchet.

# (scripts/complement-check.py). Pull requests run exactly this protected
# subset; pushes to main run the whole suite and print newly passing tests
# as candidates. Promotion into this list is a reviewed decision: a test
# enters after passing two consecutive full local runs (the baseline and a
# verification re-run), never automatically — a flaky test promoted by a
# script would teach everyone to ignore this gate.
#
# Names are Go test names as Complement reports them, one per line;
# subtests are protected individually, so a parent whose other children
# still fail does not block protecting the children that pass.
#
